# 缘分测试

输入两个人的名字，算出缘分值和对应的五档评级。全程在浏览器本地计算，名字不会离开设备。

**在线体验：** https://brucedub.github.io/fate-test/

## 五档

| 分数 | 档位 | 评语 |
|---|---|---|
| 90–100 | 天作之合 | 别人磨合一辈子，你们一见就默认对方是对的。 |
| 75–89 | 情深似海 | 吵完架还记得对方爱吃什么，这事骗不了人。 |
| 55–74 | 细水长流 | 没有一见钟情，但你们的感情耐放，不会过期。 |
| 35–54 | 似是而非 | 你俩都在等对方先低头，谁先开口谁就赢。 |
| 0–34 | 缘浅难聚 | 不怪缘分薄，是你们总在最关键的时候错开半步。 |

## 算法

名字里每个汉字取四个维度，加权合成 0–100 分：

| 维度 | 权重 | 依据 |
|---|---|---|
| 五行 | 40% | 康熙部首定五行，分同气 / 生我 / 我生 / 我克 / 克我 |
| 笔画 | 25% | 双方总笔画接近度 + 笔画尾数吉凶（3、8 吉利，4、9 凶险） |
| 音律 | 20% | 首字平仄是否相合、尾字是否撞韵、开口音与闭口音是否互补 |
| 形构 | 15% | 姓+名字数是否齐整、笔画繁简搭配、是否含同一个字 |

原始分经 30 万组随机真实姓名的经验分位数映射到最终分数，保证五档都有真实分布。
同一对名字永远得到同一个结果（FNV-1a 哈希做种子，仅 ±4 分扰动）。

## 数据来源

汉字数据取自 [Unicode Unihan 数据库](https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip)（UCD 18.0.0）的
`kTotalStrokes`（笔画）、`kRSUnicode`（康熙部首）、`kMandarin`（普通话读音），打包 20992 个汉字内嵌在页面里。
